Edge Test Cases for Vehicle App
===============================

Test Case 1: Invalid Vehicle Type
Input: 4, 3, Model S, Red, L R
Expected: Error - Invalid vehicle type: 4

Test Case 2: Invalid Autonomy Level (Too High)
Input: 1, 6, Model S, Red, L R
Expected: Error - Invalid autonomy level. Must be between 1 and 5.

Test Case 3: Invalid Autonomy Level (Too Low)
Input: 1, 0, Model S, Red, L R
Expected: Error - Invalid autonomy level. Must be between 1 and 5.

Test Case 4: Empty Model Name
Input: 1, 3, "", Red, L R
Expected: Error - Model cannot be empty.

Test Case 5: Empty Color
Input: 1, 3, Model S, "", L R
Expected: Error - Color cannot be empty.

Test Case 6: Invalid Turn Direction
Input: 1, 3, Model S, Red, L R X
Expected: Error - Invalid turn: X. Only L and R are allowed.

Test Case 7: Invalid GM Vehicle Type
Input: 3, 3, Cruise, White, truck, L R
Expected: Error - Invalid GM vehicle type. Must be pod, robotaxi, or car.

Test Case 8: Non-numeric Vehicle Type
Input: abc, 3, Model S, Red, L R
Expected: Error - Invalid input format. Please enter numbers where required.

Test Case 9: Valid Tesla with Complex Turns
Input: 1, 4, Model S, Red, L L L
Expected: Tesla vehicle facing East (E)

Test Case 10: Valid Toyota
Input: 2, 3, Prius, Blue, R R R L
Expected: Toyota vehicle facing South (S)

Test Case 11: Valid GM with Robotaxi
Input: 3, 5, Cruise, White, robotaxi, R R R R
Expected: GM vehicle facing North (N)

Test Case 12: Empty Turn Sequence
Input: 1, 3, Model S, Red, ""
Expected: Vehicle facing North (N) - no turns applied
